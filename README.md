# Apolo Canvas

Apolo Canvas is an Obsidian plugin that provides hybrid Markdown + digital ink canvases (handwriting and drawing) inside notes. This repository contains the plugin source (TypeScript + esbuild) and supporting tests.

Quick facts
- Plugin id: `apolo-canvas` (in `manifest.json`)
- Package name: `apolo-canvas` (in `package.json`)
- Repo remote: `https://github.com/4-LESS/Apolo-canvas.git`

Repository layout
- `src/` — TypeScript source for the plugin (engine, UI, model, plugin entry points, tests).
- `main.js` — built bundle consumed by Obsidian (generated by the build step).
- `ApoloCanvas/data/` — centralized runtime data folder used by the plugin inside the vault (legacy code may still reference `ObsidianInk/data/`).

Development

Prerequisites: Node 18+ and npm.

- Install dependencies:

```bash
npm install
```

- Build (produces `main.js`):

```bash
npm run build
```

- Watch / dev build:

```bash
npm run dev
```

- Run tests:

```bash
npm test
```

Local install in Obsidian (for development)

1. Build the plugin: `npm run build`.
2. Copy the plugin folder into your vault's plugins directory (example path):

```bash
# from repo root
cp -R . "$HOME/.obsidian/plugins/ApoloCanvas"
```

3. In Obsidian, enable the plugin in Settings -> Third-party plugins.

Notes about migration and names

- The project was previously published as "Obsidian Ink". Source identifiers and stored data paths were updated in this repo to `ApoloCanvas` / `apolo-canvas` where feasible.
- Some legacy references (e.g., in user vaults or older bundles) may still use `ObsidianInk/data/` or console tags like `[ObsidianInk]`. If you maintain existing user data, run the included migration routines or manually move data from `ObsidianInk/` → `ApoloCanvas/` in the vault.

Publishing / GitHub

To push to the configured remote and publish the repo:

```bash
git add -A
git commit -m "chore: rename to Apolo Canvas and initial setup"
git branch -M main
git remote add origin https://github.com/4-LESS/Apolo-canvas.git
git push -u origin main
```
